# 2. Concepto del Juego

## Historia Breve

Un grupo de estudiantes de educación primaria entra a un desafío interactivo de gramática y ortografía. Durante la partida, los alumnos reciben cartas con diferentes palabras aleatorias y deben clasificarlas correctamente arrastrándolas a los contenedores correspondientes de palabras **graves** o **esdrújulas**, aprendiendo las reglas de acentuación de manera práctica y visual.

## Objetivo Principal del Jugador

Demostrar la comprensión de las reglas de acentuación en español arrastrando y ordenando correctamente cada carta en su categoría ortográfica correspondiente para acumular la máxima puntuación.

---

## Características Clave

### Mecánicas Principales

- Mecánica de arrastrar y soltar (*drag and drop*) de cartas con palabras ortográficas.
- Clasificación interactiva en categorías bien definidas (Esdrújulas y Graves).
- Generación de palabras aleatorias para aumentar la rejugabilidad.
- Retroalimentación visual inmediata ante aciertos o errores.
- Navegación e interfaz intuitiva y accesible mediante mouse, touchpad o pantalla táctil.

### Estilo Visual

Diseño en 2D inspirado en juegos de cartas casuales y de acertijos, con colores vivos, tipografía clara de fácil lectura para educación primaria y cartas visualmente atractivas. La interfaz cuenta con áreas de clasificación (contenedores) claramente diferenciadas y animaciones fluidas al arrastrar y soltar.

### Música y Sonido

El juego incluye música ambiental ligera y motivadora que favorece la concentración.

# 3. Instalación y Uso

## Requisitos Mínimos

- Sistema Operativo: Windows / Navegador Web actualizado.
- Procesador: Doble núcleo a 1.6 GHz o superior.
- Memoria RAM: 2 GB a 4 GB.
- Dispositivos de entrada: Teclado y mouse (o pantalla táctil).


## Requisitos Recomendados

- Sistema Operativo: Windows 10/11 o navegador moderno con aceleración por hardware.
- Procesador: Intel Core i3 o equivalente.
- Memoria RAM: 4 GB o superior.
- Pantalla: Resolución HD (1280x720) o superior para óptima visualización de cartas e interfaz.
